# 彩虹待办 · 设计说明

## 1. 产品定位

**一句话**：用彩虹色给生活分类，用勾选记录进步。

面向「想在手机上随手记一件小事」的用户，强调三件事：

1. **低门槛**：首页一个 + 按钮，输入标题即可保存，平均 3 秒完成一次记录。
2. **正反馈**：勾选有震动与进度变化，全部完成时给出整屏庆祝提示。
3. **轻负担**：不做复杂的项目管理，不强制分类、标签、提醒；颜色可选，日期可选，备注可选。

## 2. 信息架构

    tabBar
    ├── 待办（pages/index/index）
    │     ├── 今日进度卡片
    │     ├── 全部 / 待办 / 已完成 筛选
    │     ├── 任务卡片列表
    │     └── ＋ 新建 → 编辑页
    ├── 统计（pages/stats/stats）
    │     ├── 四个关键指标
    │     ├── 近 7 天完成柱状图
    │     └── 彩虹分布
    └── 我的（pages/mine/mine）
          ├── 个人信息与连续打卡
          ├── 昵称 / 每日目标 / 震动开关
          └── 清理、导出、重置

编辑页（pages/editor/editor）是二级页面，从首页浮动按钮或任务卡片进入。

## 3. 视觉规范

### 3.1 色彩

| 名称 | 色值 | 语义建议 |
| --- | --- | --- |
| 草莓红 | #FF6B6B | 紧急、热情 |
| 蜜橘橙 | #FFA94D | 生活、家务 |
| 柠檬黄 | #FFD43B | 灵感、备忘 |
| 青草绿 | #51CF66 | 健康、运动 |
| 薄荷青 | #20C997 | 财务、日常 |
| 晴空蓝 | #4DABF7 | 工作、沟通 |
| 葡萄紫 | #9775FA | 学习、创作 |
| 樱花粉 | #F783AC | 关系、自我关怀 |

- 背景：<code>#F6F7FB</code>
- 正文：<code>#24293A</code>；次级：<code>#6B7288</code>；弱化：<code>#9AA0B4</code>
- 分割线：<code>#EEF0F7</code>

颜色不承担唯一语义：进度文案、逾期文案、优先级标签都会同时给出文字信息。

### 3.2 字体与字号

系统字体（PingFang SC / Microsoft YaHei），字重以 600 / 700 / 800 表达层级：

- 首页品牌标题 68rpx / 800
- 页面标题 44–56rpx / 800
- 任务标题 30rpx / 600
- 正文 26–28rpx / 400
- 辅助信息 22–24rpx / 400

### 3.3 形状与空间

- 卡片圆角 32rpx，任务卡片 28rpx，标签 8rpx，按钮与筛选胶囊 999rpx。
- 页面左右留白 32rpx，卡片内边距 28–32rpx。
- 阴影：<code>0 12rpx 36rpx rgba(38, 45, 82, 0.07)</code>，不使用纯黑。

### 3.4 图标

tabBar 图标为 81×81 PNG，线性风格、5px 描边：房子（待办）、柱状图（统计）、人像（我的）。普通态 <code>#9AA0B4</code>，选中态分别使用粉、蓝、紫，呼应彩虹主题。图标由 <code>tools/gen_icons.py</code> 以 4 倍超采样绘制后缩放，保证边缘锐利。

## 4. 交互设计

### 4.1 首页

- 顶部展示日期、问候语与昵称，吉祥物为彩虹弧线。
- 今日进度卡：今天完成数 / 每日目标，右侧百分比胶囊，底部彩虹进度条。
- 筛选胶囊即时切换，列表保持排序：未完成优先 → 按截止日期升序 → 同日期按优先级降序 → 按创建时间降序；已完成按完成时间倒序。
- 任务卡片：左侧色条表达分类，圆圈勾选，标签显示颜色名、截止日期、优先级；备注单行省略。
- 点击卡片进入编辑；点击圆圈完成（不触发卡片点击，使用 catchtap）；长按弹出操作面板。
- 全部完成时弹出「全部完成，彩虹满分！」提示，并伴随轻震动（可在「我的」关闭）。

### 4.2 编辑页

- 标题必填，空白时提示「先写下要做什么吧」，不写入存储。
- 颜色 8 选 1，单行排布，选中项放大并加白边，下方显示颜色中文名。
- 优先级三段式控件；截止日期提供今天 / 明天 / 后天快捷项与日期选择器，可一键清除。
- 保存成功 Toast 后自动返回；编辑态额外提供删除入口，删除前二次确认。

### 4.3 统计页

- 四个指标卡：全部待办、已完成、本周完成、连续打卡。
- 柱状图展示近 7 天完成数，今天用紫蓝渐变强调；无数据时保留 4% 高度占位。
- 彩虹分布按最大值为 100% 归一化，直观看出颜色偏好。
- 底部每日一句鼓励文案，按自然日轮换。

### 4.4 我的页

- 昵称修改后失焦保存，空值回落到默认「彩虹追梦人」。
- 每日目标 1–10 步进，越界时按钮置灰。
- 清理已完成、清空所有数据均需二次确认；导出数据写入剪贴板 JSON。

### 4.5 空状态

三种筛选对应三套文案，避免「空白页焦虑」：

- 全部：还没有待办 / 点击右下角 +，写下第一件想做的事
- 待办：没有未完成的待办 / 今天可以给自己一点小奖励
- 已完成：还没有完成记录 / 完成一件小事，彩虹就会亮起来

## 5. 数据与算法

### 5.1 存储

- <code>rainbow_tasks_v1</code>：任务数组。
- <code>rainbow_settings_v1</code>：<code>{ nickname, dailyGoal, celebrate }</code>。

读取时做归一化：补默认值、裁剪标题空白、优先级越界回落、过滤重复 id 与非法对象。写入失败（如存储超限）静默降级，不阻断交互。

### 5.2 关键计算

- **今日进度**：<code>min(100, round(今日完成 / 每日目标 × 100))</code>。
- **周趋势**：从今天往前 6 天，逐日统计 <code>doneAt</code> 落在该日的任务数。
- **连续打卡**：若今天有完成记录则从今天起算，否则从昨天起算；向前逐日回溯，遇到断档停止。
- **相对日期**：今天 / 明天 / 后天 / 昨天 / 逾期 N 天 / N 天后 / 月日。
- **日期计算**：以 <code>Date.UTC</code> 计算天差，避免时区与夏令时误差。

## 6. 技术实现

- 原生微信小程序：WXML + WXSS + JavaScript（CommonJS 模块）。
- 无第三方依赖、无网络请求、无云开发，冷启动快。
- 页面通过 <code>onShow</code> 重新读取存储，保证跨页数据一致。
- 工具层与页面层分离，工具层不依赖 <code>Page</code>，可直接在 Node 中测试。

## 7. 可访问性与边界

- 主文字与背景对比度满足日常阅读；彩色标签同时有文字说明。
- 点击区域：勾选圆 44rpx、按钮高度 ≥ 88rpx，满足触控热区。
- 长标题与备注分别使用换行与单行省略，避免撑破卡片。
- 日期为空、任务为空、存储损坏、未知任务 id 均有兜底路径。

## 8. 测试与验收

- 单元测试：日期、颜色、存储、排序、统计共 31 项。
- 页面集成测试：mock <code>wx</code> / <code>Page</code>，覆盖四个页面的生命周期与主要事件，共 15 项。
- 静态检查：JSON、页面文件完整性、JS 语法、WXSS 括号、WXML 标签与事件绑定、图标尺寸，共 88 项。
- 设计还原：<code>tools/render_preview.py</code> 按真实 WXML/WXSS 数值绘制三屏预览图。
